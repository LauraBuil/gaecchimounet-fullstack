# Site du GAEC Chimounet

Application React avec un espace public et une administration de contenus basée
sur Supabase.

- Le frontend se trouve dans `gaec-chimounet-frontend/`.
- Le schéma, les permissions et la fonction serveur se trouvent dans `supabase/`.
- La procédure complète de démarrage se trouve dans `INSTALLATION.md`.
- L'avancement et les derniers points avant mise en ligne sont suivis dans
  `ETAT-DES-LIEUX.md`.

La CI/CD sera ajoutée après la validation fonctionnelle et le choix de
l'hébergement.
